# Product Direction

## Original aim

DeckForge helps coding agents create presentation experiences that live on the web and behave like products, not exported documents. The artifact should support editing, presenting, sharing, embedding, and interacting in one coherent application.

## Product surfaces

### Editor mode

- Slide rail or outline tree
- Direct manipulation canvas
- Contextual toolbar and command palette
- Insert, arrange, align, group, lock, duplicate, undo/redo
- Theme, layout, animation, notes, comments, and accessibility panels
- Autosave and explicit version boundary in production implementations

### Presenter mode

- Fullscreen canvas without editor chrome
- Keyboard, touch, and remote-friendly navigation
- Build animations before slide navigation
- Speaker notes, next-slide preview, timer, and overview
- Deep links to sections or slides
- Reduced-motion fallback
- Optional live demos, polls, Q&A, charts, video, and embeds

### Audience mode

- Responsive public or unlisted page
- Readable on desktop, tablet, and mobile
- Embed contract with origin allow-list and sandbox policy
- Optional comments, reactions, polls, or follow-up links
- Analytics only when privacy policy and consent requirements are satisfied

## What DeckForge rejects

- Treating every slide as a screenshot
- Generating a generic gradient hero followed by repeated cards
- Using one visual style for every industry
- Shrinking type until content fits
- Decorative motion without narrative purpose
- Invented metrics, references, customer logos, or product UI
- Untrusted raw HTML in slide content
