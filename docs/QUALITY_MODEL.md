# Quality Model

A deck is not complete when it merely renders. It passes when story, content fit, visual hierarchy, interaction, accessibility, performance, and trust all meet the rubric in `skills/deckforge/assets/quality-rubric.json`.

## Blocking conditions

- Clipped or overflowed content
- Unreadable text at presentation distance
- Broken keyboard navigation
- Missing focus states or alt text
- Motion that ignores reduced-motion preferences
- Untrusted raw HTML
- Placeholder data or invented citations
- Presenter mode that still exposes editing controls

## Anti-slop review

The quality pass explicitly searches for repeated card grids, excessive gradients, decorative glass panels, random icons, generic titles, unexplained neon AI styling, and visuals that do not carry information.
