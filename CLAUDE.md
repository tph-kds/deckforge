# DeckForge Claude Code Guide

Read `AGENTS.md`, then activate the relevant skill under `skills/`. The primary entry point is `skills/deckforge/SKILL.md`.

Keep the repository provider-portable. Do not add a production backend, database, authentication, billing, or deployment runtime here. Reference components are allowed under `skills/deckforge/starter-components/` and must remain copyable, framework-clear, and free of secrets.
