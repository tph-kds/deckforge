# Browser Evidence Contract

## Rules

- Evidence is generated by a trusted runner (Playwright/export/browser), at a known commit and run ID, into an artifact with a SHA-256.
- A source test file or a manually declared pass is not evidence.
- A capability may be recorded `implemented` only when an executed evidence entry with status `passed` exists for it.
- Checks that could not run are `unverified`, never `passed`.
- Viewport coverage: authored 16:9, a common laptop viewport, and one narrow viewport. Reduced motion is tested explicitly.
- Required captures: editor shell, cover, dense slide, data slide, diagram, narrow viewer, reduced-motion mode, presenter, overview, speaker view, and export rendering.

## Evidence entry shape

See `schemas/capability-evidence.schema.json`. Required fields: kind, testId, status=passed, commit, runId, artifact, artifactSha256, startedAt, finishedAt.

## Rejection rules

Reject evidence from another commit, missing hashes, skipped tests, source test files presented as evidence, and manually declared passing results without a trusted runner.
