# Browser Evidence Contract

Evidence is generated by a trusted runner at a known commit and run ID, into an
artifact with a SHA-256. A source test file or a manually declared pass is not
evidence. Capabilities with no passing evidence are `unverified`, never `passed`.

Required captures: editor shell, cover, dense slide, data slide, diagram, narrow
viewer, reduced-motion mode, presenter, overview, speaker view, and export rendering.
Viewports: authored 16:9, a laptop viewport, and a narrow viewport.

Evidence entry shape: see `schemas/capability-evidence.schema.json`.
Reject: another commit, missing hashes, skipped tests, source files as evidence,
manually declared passes.
