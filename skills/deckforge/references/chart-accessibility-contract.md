# Chart Accessibility Contract

Every chart block provides:

- a concise text takeaway;
- a tabular or textual data alternative;
- color plus a secondary encoding (labels, marks, patterns, or direct values);
- keyboard behavior when interactive, with announced values and logical order;
- a caption and source, with units, time range, and denominator stated;
- export-specific accessibility-loss reporting.

Release classifications: blocking for publish/export; profile-blocking (professional
profile but allowed in draft); advisory repair; accepted format-specific loss with
explicit disclosure. Never encode status, series, or emphasis by color alone.
