# Provider Routing Contract

Provider output is suggested, normalized, validated, and persisted with provenance —
never applied as raw authority. Precedence: explicit user requirements; security,
privacy, legal, and accessibility; existing brand and architecture; DeckForge
document/capability invariants; surface-specific UX; presentation archetype;
optional provider recommendations; taste heuristics; decoration.

Optional providers: ui-ux-pro-max (design-intelligence), dembrandt
(design-extraction), figma (design-source), mermaid (diagram). The built-in
fallback is always available.
