# Language and Syntax

- Follow the user's language; keep code identifiers in English.
- Markdown instructions put operational steps before rationale.
- JSON is valid, deterministic, and uses stable IDs.
- Python validation exits non-zero on failure and declares non-standard dependencies in `requirements-dev.txt`.
- TypeScript reference code uses explicit types, serializable state, and no `any` unless justified.
- URLs in examples use safe placeholder domains.
