# Design Quality

- Start from audience, objective, and narrative before selecting a theme.
- Use one dominant idea per slide.
- Treat templates as adaptable story structures, not mandatory filler.
- Build a coherent grid, type scale, spacing scale, shape language, and chart language.
- Use visuals to explain, compare, prove, or orient.
- Never shrink content below readable presentation size to make it fit.
- Run the quality rubric and anti-slop detectors before completion.
